CARA PALING MUDAH
1. Buka folder website.
2. Double-click SETUP-RESEND.bat.
3. Paste API key BARU dari Resend saat diminta. Jangan kirim key ke siapa pun.
4. Setelah selesai, double-click START-WEBSITE.bat.
5. Buka http://localhost:3000/test-order-email
6. Klik KIRIM TEST PESANAN.
7. Cek Resend -> Emails dan Gmail tujuan.

Jika test berhasil, lanjutkan transaksi COD/QRIS/PayPal.
