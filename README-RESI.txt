FITUR RESI PENGIRIMAN 16FLAMES

1. Buat order seperti biasa.
2. Buka http://localhost:3000/admin/shipping di browser yang sama.
3. Pilih ORDER.
4. Pilih status pengiriman, kurir, lalu masukkan nomor resi.
5. Klik SIMPAN RESI.
6. Buka bukti transaksi. Bagian PENGIRIMAN akan menampilkan status, kurir, nomor resi, tombol salin, dan tombol lacak.

Catatan: URL pelacakan mengikuti situs resmi masing-masing kurir jika tersedia. 17TRACK dapat digunakan sebagai pelacak universal untuk nomor resi internasional yang berasal dari berbagai operator.

PENTING: versi testing ini menyimpan data order/resi di localStorage browser. Untuk production, resi harus disimpan di database/server agar pembeli dapat melihat resi dari perangkat mereka sendiri.
